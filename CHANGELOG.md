# v0.2.1 MIME / Vite development fix

- Control server no longer serves raw React/TypeScript source when `web-console/dist` is missing.
- Development Web Console must be served by Vite on `http://localhost:5173`.
- Production control server serves only `web-console/dist` generated by `./phoneweave web-build`.
- Added explicit MIME mappings for common production static assets.
- Removed the misleading VS Code launch configuration that opened the control server (`:8787`) as if it were the Vite UI.
